配置文件规格

配置文件是文件类型、隐藏规则和分页默认值的唯一事实源。

1. 责任边界

config-spec.html 是文件类型分组、默认隐藏规则、分页默认值和配置覆盖规则的唯一事实源。其他文档只引用本文件，不重复列出默认扩展名清单。

2. 配置格式

初版采用 TOML，原因是 Python 3.11+ 可用标准库 tomllib 读取，格式可读性较好，适合手写配置。

默认配置文件名建议为 tunnel-preview.toml。CLI 可通过 --config 指定显式路径。

3. 默认配置

[server]
host = "127.0.0.1"
port = 5500
page_size = 100

[renderers]
max_file_bytes = 5242880

[files]
direct = [".html", ".jpg", ".jpeg", ".png", ".webp", ".mp4"]
rendered = [".md", ".pdf", ".json", ".yaml", ".yml"]

[hide]
patterns = [
  ".git/",
  ".env"
]
维护规则：新增或移除默认扩展名、默认隐藏项、默认监听值、默认 page size 或 renderer 大小限制时，只修改本节。测试、设计、安全和 renderer 文档均引用本节。

4. 字段语义

字段语义约束
server.host默认监听地址。默认 127.0.0.1；远程开发通常通过端口转发访问，需要外部监听时显式设为 0.0.0.0。
server.port默认监听端口。必须为 1-65535 的整数。
server.page_size目录页单页最大条目数。必须为正整数；实现可设置上限，避免超大页面。
renderers.max_file_bytesrenderer 可处理的单文件最大字节数。默认 5242880，即 5 MiB；超过后显示“文件过大，请用 SSH/编辑器查看”。
files.direct浏览器成熟支持、服务端可直接静态返回的扩展名。扩展名必须小写且以点开头；匹配时大小写不敏感。
files.rendered需要项目内 renderer 输出阅读页面的扩展名。不能与 files.direct 重叠；重叠时启动失败。
hide.patterns目录列表与直接访问都应隐藏的路径规则。采用 gitignore-like 语义的安全子集。

5. 覆盖与合并规则

  1. 内置默认配置先加载。
  2. 配置文件覆盖默认配置。对于数组字段，配置文件值视为完整替换，而不是追加；这是已确认规则。
  3. CLI 参数覆盖配置文件，例如 --page-size、--root、--host、--port。
  4. 如未来需要追加语义，应新增显式字段，例如 files.direct_add，不要让同一字段同时承担覆盖和追加。

6. 配置查找顺序

  1. 如果传入 --config，只读取该文件；不存在或非法则启动失败。
  2. 如果未传入 --config，在 root 目录查找 tunnel-preview.toml。
  3. 如果不存在配置文件，使用内置默认配置。

7. hide patterns 语义

隐藏规则采用 gitignore-like 的安全子集。初版建议支持：

  • name：匹配任意层级同名文件或目录。
  • name/：匹配任意层级同名目录。
  • *.ext：匹配扩展名模式。
  • path/to/item：匹配相对于 root 的路径。

初版不支持 ! 否定规则。以 ! 开头的 pattern 应视为非法配置并在启动时失败，避免隐藏逻辑难以审计。

维护约定：跨文档共享的默认值只在本规格中记录，其他文档引用本规格，避免重复维护。
