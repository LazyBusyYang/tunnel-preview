tunnel-preview 项目设计

一个面向远程开发场景的受限文件预览服务：通过 FastAPI 暴露指定目录下的 HTML、图片和视频文件，同时隐藏并拒绝访问不支持的文件类型。

项目名：tunnel-preview Python package：tunnel_preview 框架：FastAPI 文档日期：2026-06-05

1. 背景与目标

本地开发时，HTML 文件通常可以直接用本地浏览器打开；而在远程开发机、容器或跳板环境中，开发者更需要一个可通过 SSH tunnel、Cursor/VS Code 端口转发访问的轻量预览服务。

tunnel-preview 的目标不是成为通用静态文件服务器，而是提供一个受限、可控、适合远程开发的查看入口。

核心原则：只展示和服务明确允许预览的文件类型；目录页不泄露不支持文件；直接输入不支持文件 URL 时拒绝访问。

2. 已确定设计

主要场景 远程机器上查看项目生成的 HTML、图片、WebP 和 MP4 文件，通过端口转发在本地浏览器打开。
技术栈 Python + FastAPI + Uvicorn，目录页由服务端渲染简单 HTML。
访问边界 所有文件访问必须限制在启动参数指定的 root 目录内，防止路径穿越。
文件白名单 白名单由配置文件驱动，可在开发过程中动态调整；浏览器成熟支持的类型直接静态返回，需要项目渲染的类型走专用 renderer。

3. 预期行为

URL 类型 行为 说明
/ 或目录 URL 显示目录页 只列出子目录和支持的文件；隐藏其他文件。
direct 文件 正常打开 按 config-spec.html 中的 direct 分组安全返回。
rendered 文件 渲染后打开 按 config-spec.html 中的 rendered 分组交给 renderers-spec.html 定义的 renderer。
隐藏或不支持文件 拒绝访问 隐藏规则和文件类型规则见 config-spec.html；直接访问返回 404。
/../outside.txt 拒绝访问 规范化路径后必须仍位于 root 内。

4. 目录页设计

目录页用于浏览远程目录结构，但不承担完整文件管理器职责。

  • 显示当前相对路径。
  • 如果不是 root，显示返回上级目录入口。
  • 优先显示子目录，再显示支持的文件。
  • 默认不隐藏点开头目录，允许进入可能包含文档的点目录。
  • 使用配置文件中的 gitignore-like 规则隐藏目录或文件；具体默认值见 config-spec.html。
  • 不显示隐藏规则命中的路径，也不显示不支持文件。
  • 控制单页长度；默认值见 config-spec.html。
  • 超过上限时使用分页，例如 ?page=2。
目录过滤是可配置策略。默认隐藏规则和 gitignore-like 语义由 config-spec.html 维护。

5. 配置文件规格

文件类型分组、默认隐藏规则、分页默认值、配置覆盖规则和配置查找顺序由 config-spec.html 维护。本文档不重复列出具体扩展名或默认隐藏项，避免后续变更时多处同步。

  • direct 表示浏览器已有成熟加载方案的类型，服务端只负责安全地返回文件。
  • rendered 表示需要项目内 renderer 的类型。
  • hide.patterns 控制目录列表和直接访问的隐藏规则。
  • 不配置访问 token；访问边界由监听地址、SSH tunnel 或远程开发端口转发控制。

6. CLI 快速启动规格

CLI 的核心体验是远程开发时在项目根目录执行 tunnel-preview 一键阻塞式启动 server；未显式设置端口时自动绑定随机可用端口。详细规则由 cli-spec.html 维护。

cd /workspace/project
tunnel-preview
  • 默认 root 为当前工作目录。
  • 命令可通过 Python console script 加入用户 PATH。
  • 默认前台阻塞运行，按 Ctrl-C 停止。
  • host、配置查找和分页默认值继续引用 config-spec.html。

7. FastAPI 路由草案

GET /healthz
  返回服务状态和 root 信息，不泄露完整敏感路径时可只返回 basename。

GET /{path:path}
  如果 path 指向目录：渲染目录页。
  如果 path 指向允许后缀文件：返回文件内容。
  如果 path 指向不支持文件：返回 404。
  如果 path 越出 root：返回 404。

实现上应使用 pathlib.Path.resolve() 规范化路径，并验证目标路径位于 root 内。

8. 安全策略

  • 默认只监听 127.0.0.1，避免无意暴露到局域网。
  • 允许符号链接，但解析后的真实路径必须仍位于 root 内；细节见 security-spec.html。
  • 目录列表只显示支持文件、允许显示的目录，以及未被隐藏规则命中的路径。
  • 隐藏规则默认值见 config-spec.html。
  • 直接访问不支持文件或隐藏规则命中的路径时返回 404；细节见 security-spec.html。
  • 响应头可加入 X-Content-Type-Options: nosniff。

10. 测试建议

  • 目录页只列出目录和支持文件。
  • 不支持文件不会出现在目录页。
  • 直接访问不支持文件被拒绝。
  • 路径穿越被拒绝。
  • 分页参数生效，单页长度受控。
  • 支持文件返回正确 media type。
  • 配置文件可调整文件白名单和隐藏规则。
  • 隐藏规则命中的文件或目录不会出现在列表中，直接访问也被拒绝。
  • 符号链接可访问，但越出 root 的链接被拒绝。
  • MP4 至少能被浏览器正常打开；后续补充 Range 请求测试。

11. 待讨论事项

  1. HTML 文件是否需要禁用或限制外部网络请求？初版建议不拦截，由浏览器和目标页面自行决定。
  2. PDF renderer 初版方案已在 renderers-spec.html 中确认：PDF 属于 rendered，使用浏览器内嵌 PDF wrapper。
  3. 是否支持自动打开浏览器？远程场景下意义有限，初版建议不做。
本文档记录当前已确定的设计边界和未定事项。后续实现时，应优先保持远程开发场景下的可控预览和低泄露面。
